# Long Horizon Agents Hack

Build agents that stay reliable over long tasks. Explore persistent state, memory, and context management, and show a working project at the end of the day.

[Submit your project](https://tokensand.com/horizonagentshack/submit) [Browse projects](https://tokensand.com/horizonagentshack/projects) [Join Discord](https://bit.ly/discord-17)

Opens 11:30 AM PT · Deadline 4:30 PM PT

One project per team · Up to 4 people

[![Long Horizon Agents Hack](https://images.lumacdn.com/uploads/mi/dcffc691-0c28-41e2-a9a9-bee2c14785fb.png)](https://luma.com/horizonagentshack)

## What to submit

- A public GitHub repository
- A short demo video with a shareable link
- What you built and the tools you used
- Your team’s names and contact emails

A working website and project screenshot are welcome. Build your project during the event.
