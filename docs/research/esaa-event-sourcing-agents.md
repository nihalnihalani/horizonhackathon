# Title:ESAA: Event Sourcing for Autonomous Agents in LLM-Based Software Engineering

Authors: [Elzo Brito dos Santos Filho](https://arxiv.org/search/cs?searchtype=author&query=Filho,+E+B+d+S)

View a PDF of the paper titled ESAA: Event Sourcing for Autonomous Agents in LLM-Based Software Engineering, by Elzo Brito dos Santos Filho

[View PDF](https://arxiv.org/pdf/2602.23193) [HTML (experimental)](https://arxiv.org/html/2602.23193v1)

> Abstract:Autonomous agents based on Large Language Models (LLMs) have evolved from reactive assistants to systems capable of planning, executing actions via tools, and iterating over environment observations. However, they remain vulnerable to structural limitations: lack of native state, context degradation over long horizons, and the gap between probabilistic generation and deterministic execution requirements. This paper presents the ESAA (Event Sourcing for Autonomous Agents) architecture, which separates the agent's cognitive intention from the project's state mutation, inspired by the Event Sourcing pattern. In ESAA, agents emit only structured intentions in validated JSON ( [this http URL](http://agent.result/) or [this http URL](http://issue.report/)); a deterministic orchestrator validates, persists events in an append-only log ( [this http URL](http://activity.jsonl/)), applies file-writing effects, and projects a verifiable materialized view ( [this http URL](http://roadmap.json/)). The proposal incorporates boundary contracts ( [this http URL](http://agent_contract.yaml/)), metaprompting profiles (PARCER), and replay verification with hashing (esaa verify), ensuring the immutability of completed tasks and forensic traceability. Two case studies validate the architecture: (i) a landing page project (9 tasks, 49 events, single-agent composition) and (ii) a clinical dashboard system (50 tasks, 86 events, 4 concurrent agents across 8 phases), both concluding with [this http URL](http://run.status/) =success and verify\_status=ok. The multi-agent case study demonstrates real concurrent orchestration with heterogeneous LLMs (Claude Sonnet 4.6, Codex GPT-5, Antigravity/Gemini 3 Pro, and Claude Opus 4.6), providing empirical evidence of the architecture's scalability beyond single-agent scenarios.
