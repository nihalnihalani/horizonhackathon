## Inferences for our entry

A concrete operational task plus an inspectable memory mechanism and a reproducible intervention is a defensible strategy. The evidence does not prove that attractive dashboards win or that infrastructure loses. A demo should show an output that actually changes because the state architecture works.

Use a task with facts that expire, commitments that persist, and irrelevant observations that can leave active context. The audience should see the consequence of each policy.

An honest accelerated replay should be labeled as such. A 90-second replay of simulated days is evidence about many-step task behavior, not proof of continuous multi-day uptime.
