- [Create Run](https://docs.nimbleway.com/api-reference/public-api/create-run.md): Creates a minimal persistent Web Search Agent and starts a run for it. The response includes `web_search_agent_id` for later agent and run queries.
- [Create Agent Run](https://docs.nimbleway.com/api-reference/public-api/create-agent-run.md): Start an agent run. The run executes asynchronously: the response returns immediately with status `queued`, then poll `GET .../runs/{run_id}` until `completed` and fetch the output from `GET .../runs/{run_id}/result` — or set `enable_events: true` and follow `GET .../runs/{run_id}/events` for live p…
- [Get Agent Run](https://docs.nimbleway.com/api-reference/public-api/get-agent-run.md): Retrieve a run's current state. Poll this endpoint after creating a run: the run is finished once `status` is `completed`, `failed`, or `cancelled`.
- [Get Agent Run Result](https://docs.nimbleway.com/api-reference/public-api/get-agent-run-result.md): Fetch the output of a completed run. The `output` is `type: "text"` (a prose answer) or `type: "json"` (structured data matching the output schema), plus `trust` metadata with per-claim citations for the answer.
- [Stream Agent Run Events](https://docs.nimbleway.com/api-reference/public-api/stream-agent-run-events.md): Stream a run's progress as [server-sent events](https://developer.mozilla.org/en-US/docs/Web/API/Server-sent_events) (`text/event-stream`). Create the run with `enable_events: true` to have events published. A keep-alive comment is sent every 15 seconds.
- [List Agent Runs](https://docs.nimbleway.com/api-reference/public-api/list-agent-runs.md): List the runs of an agent, newest first, paginated with `offset`/`limit`.
- [Create Agent](https://docs.nimbleway.com/api-reference/public-api/create-agent.md): Create a Web Search Agent. Either pass `template` to materialize a pre-built template (its fields, goals, sources, and suggested questions are copied), or define the agent from scratch with `display_name`, `goals`, `sources`, and an optional `output_schema` for structured results.
- [List Agents](https://docs.nimbleway.com/api-reference/public-api/list-agents.md): List the active Web Search Agents in your account. Results are scoped to the workspace resolved from your token (or the optional `workspace_id` query parameter) and paginated with `offset`/`limit`.
- [Get Agent](https://docs.nimbleway.com/api-reference/public-api/get-agent.md): Retrieve a single Web Search Agent by ID.
- [Update Agent](https://docs.nimbleway.com/api-reference/public-api/update-agent.md): Update an agent with a [JSON Patch](https://datatracker.ietf.org/doc/html/rfc6902) document — an array of `{op, path, value}` operations applied to the agent, e.g. `[{"op": "replace", "path": "/display_name", "value": "My agent"}]`. Returns the updated agent.
- [Deactivate Agent](https://docs.nimbleway.com/api-reference/public-api/deactivate-agent.md): Deactivate an agent. This is a soft delete: the agent can no longer start new runs, but its existing runs and their results remain retrievable.
- [List Agent Templates](https://docs.nimbleway.com/api-reference/public-api/list-agent-templates.md): List the pre-built agent templates available to your account. Use a template's `template_name` with `POST /v2/agents` to create an agent instance from it.
- [Get Agent Template](https://docs.nimbleway.com/api-reference/public-api/get-agent-template.md): Retrieve a single agent template by its stable `template_name`.
